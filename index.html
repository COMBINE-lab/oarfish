oarfish

Transcript-level quantification from long-read RNA-seq (Oxford Nanopore cDNA and direct RNA, and PacBio), with multi-mapping reads allocated by an EM algorithm.
Get startedView on GitHub

oarfish is a program, written in Rust, for quantifying transcript-level expression from long-read sequencing technologies. It handles multi-mapping reads through probabilistic allocation via an expectation-maximization (EM) algorithm.

Several ways in

Quantify a transcriptome BAM, let oarfish map raw reads to the transcriptome for you (with rammap or spearfish), or start from the genome and project alignments onto annotated transcripts. See Quantification modes.

Models for where reads land

Optional coverage and truncation models use where reads fall on each transcript to improve accuracy. See Coverage and truncation models.

Filters

Optional filters, derived from NanoCount1, discard alignments that may reduce accuracy. See Command-line options.

Uncertainty and detail

Inferential replicates by bootstrap, read-level assignment probabilities, and a single-cell mode. See Output files.

oarfish is scientific software in active development. Please check the GitHub Releases page to make sure that you are using the latest version.
