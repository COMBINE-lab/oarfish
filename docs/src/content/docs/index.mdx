import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

`oarfish` is a program, written in [Rust](https://www.rust-lang.org/), for quantifying transcript-level expression from long-read sequencing technologies. It handles multi-mapping reads through probabilistic allocation via an expectation-maximization (EM) algorithm.

<CardGrid>
	<Card title="Several ways in" icon="puzzle">
		Quantify a transcriptome BAM, let `oarfish` map raw reads to the transcriptome for you
		(with rammap or spearfish), or start from the genome and project alignments onto annotated
		transcripts. See [Quantification modes](/oarfish/guides/quantification-modes/).
	</Card>
	<Card title="Models for where reads land" icon="random">
		Optional coverage and truncation models use where reads fall on each transcript to
		improve accuracy. See [Coverage and truncation models](/oarfish/guides/models/).
	</Card>
	<Card title="Filters" icon="setting">
		Optional filters, derived from [NanoCount](https://github.com/a-slide/NanoCount)[^Gleeson],
		discard alignments that may reduce accuracy. See
		[Command-line options](/oarfish/reference/command-line/).
	</Card>
	<Card title="Uncertainty and detail" icon="list-format">
		Inferential replicates by bootstrap, read-level assignment probabilities, and a
		single-cell mode. See [Output files](/oarfish/reference/output/).
	</Card>
</CardGrid>

`oarfish` is scientific software in active development. Please check the [GitHub Releases](https://github.com/COMBINE-lab/oarfish/releases) page to make sure that you are using the latest version.
